นโยบายความเป็นส่วนตัว มีผลบังคับใช้วันที่: 25 กันยายน 2026 นโยบายความเป็นส่วนตัวนี้อธิบายวิธีการที่โปรเจกต์นี้เก็บ ใช้ และจัดการข้อมูลเมื่อผู้ใช้เชื่อมต่อบัญชี Facebook หรือ Facebook Page กับระบบของเรา 1. ข้อมูลที่เราเข้าถึง เมื่อผู้ใช้อนุญาตให้ระบบเชื่อมต่อกับ Facebook เราอาจเข้าถึงข้อมูลที่จำเป็นต่อการทำงานของระบบ เช่น - ข้อมูลพื้นฐานของบัญชี Facebook ที่ได้รับอนุญาต - ข้อมูล Facebook Page ที่ผู้ใช้มีสิทธิ์จัดการ - Page ID - Access Token ที่จำเป็นสำหรับการเรียกใช้ Meta Graph API - ข้อมูลที่ผู้ใช้ส่งหรืออนุญาตให้ระบบจัดการผ่าน Facebook Page เราจะเข้าถึงเฉพาะข้อมูลที่จำเป็นต่อการทำงานของระบบและตามสิทธิ์ที่ผู้ใช้อนุญาตเท่านั้น 2. การใช้ข้อมูล ข้อมูลที่เข้าถึงจะถูกใช้เพื่อ: - เชื่อมต่อระบบกับ Facebook Page - ดำเนินการตามคำสั่งของผู้ใช้ - อ่านหรือจัดการข้อมูลของ Facebook Page ตามสิทธิ์ที่ได้รับ - ปรับปรุงและดูแลการทำงานของระบบ เราจะไม่ใช้ข้อมูลดังกล่าวเพื่อวัตถุประสงค์อื่นนอกเหนือจากที่ระบุไว้ เว้นแต่จะได้รับอนุญาตหรือมีกฎหมายกำหนด 3. การจัดเก็บข้อมูล ระบบจะพยายามจัดเก็บข้อมูลให้น้อยที่สุดเท่าที่จำเป็นต่อการทำงาน Access Token และข้อมูลที่มีความสำคัญจะต้องได้รับการจัดเก็บอย่างปลอดภัย และไม่ควรเปิดเผยต่อบุคคลอื่น 4. การเปิดเผยข้อมูล เราจะไม่ขาย ให้เช่า หรือเผยแพร่ข้อมูลส่วนบุคคลของผู้ใช้แก่บุคคลอื่น ข้อมูลอาจถูกส่งไปยัง Meta Platform เท่าที่จำเป็นสำหรับการทำงานของระบบและตามข้อกำหนดของ Meta 5. การรักษาความปลอดภัย เราดำเนินมาตรการที่เหมาะสมเพื่อป้องกันการเข้าถึง การเปิดเผย การแก้ไข หรือการทำลายข้อมูลโดยไม่ได้รับอนุญาต อย่างไรก็ตาม ไม่มีระบบส่งข้อมูลหรือระบบจัดเก็บข้อมูลใดที่สามารถรับประกันความปลอดภัยได้ 100% 6. การลบข้อมูล ผู้ใช้สามารถขอให้ลบข้อมูลที่ระบบจัดเก็บไว้ได้ โดยติดต่อเจ้าของโปรเจกต์ผ่านช่องทางติดต่อที่ระบุไว้ในหน้าโปรเจกต์ นอกจากนี้ ผู้ใช้สามารถยกเลิกสิทธิ์การเข้าถึงแอปได้จากการตั้งค่าบัญชี Facebook 7. การเปลี่ยนแปลงนโยบาย เราอาจปรับปรุงนโยบายความเป็นส่วนตัวนี้เป็นครั้งคราว หากมีการเปลี่ยนแปลงที่สำคัญ เราจะปรับปรุงวันที่มีผลบังคับใช้บนหน้านี้ 8. ติดต่อเรา หากมีคำถามเกี่ยวกับนโยบายความเป็นส่วนตัวหรือการจัดการข้อมูล สามารถติดต่อเจ้าของโปรเจกต์ผ่านช่องทางติดต่อของโปรเจกต์ ชื่อโปรเจกต์: [Ph_autoflow] อีเมล: [phongsakon0834977310@gmail.com] --- © 2026 [Ph_autoflow]
